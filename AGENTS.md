## Agent skills

Issues are tracked as local Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The standard five workflow labels are used. See `docs/agents/triage-labels.md`.

This is a single-context project. See `docs/agents/domain.md`.

### Commit approval

Whenever a change is made, seek the user's explicit approval before creating a Git commit. Never auto-commit, including after successful tests, reviews, or completed implementation work.
